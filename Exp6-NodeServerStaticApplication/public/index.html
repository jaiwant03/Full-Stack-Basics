Static JSON Data,
Served Through a REST API

A simple Node.js application that serves structured JSON data through REST API endpoints.

Server running at http://localhost:5000

Available API Endpoints

Click "Try API" on any card to send a live request and view the JSON response below.

GET /api/status

Check whether the API server is running and get server information.

GET /api/products

Retrieve all products from the static JSON file.

GET /api/products/:id

Retrieve a specific product using its numeric ID.
